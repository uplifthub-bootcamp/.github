# Security policy

SecAware is a training project written by people who are learning. It has not had a security audit, so please do not use it to store anything sensitive yet.

## Report a problem

Please do not open a public issue. Instead, open the affected repo's **Security** tab and choose **Report a vulnerability**. That sends a private report to the maintainers.

Please include what you found, how to reproduce it, and what could go wrong. We will reply as soon as we can.

## Scope

Please test only against a copy you run yourself. Do not test against other people's accounts or data.
