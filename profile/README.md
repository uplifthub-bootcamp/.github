# Uplift Hub Boot Camp

We are building **SecAware** in the open: a free platform where anyone can take short cybersecurity-awareness courses, answer questions and earn a small certificate. It starts as a training project and will launch publicly later.

| Repo | What it holds |
| --- | --- |
| [secaware-api](https://github.com/uplifthub-bootcamp/secaware-api) | JSON API in plain PHP |
| [secaware-web](https://github.com/uplifthub-bootcamp/secaware-web) | Website in HTML, CSS and JavaScript |
| [secaware-mobile](https://github.com/uplifthub-bootcamp/secaware-mobile) | Flutter app |
| [secaware-infra](https://github.com/uplifthub-bootcamp/secaware-infra) | Containers, CI and deployment |

Each issue doubles as a written lesson, so you can follow the project by reading the issues and pull requests in order.
